# RWA GIS Analysis Outputs

This folder contains generated outputs from the GIS-based
Real Estate RWA underwriting and coastal-change analysis.

## Files

- rwa_property_locations.png
- rwa_coastal_change_map.png
- rwa_coastal_linkage.csv
- rwa_coastal_evidence_table.csv
- rwa_portfolio_with_coastal_evidence.csv

The maps and tables use illustrative property coordinates.
Coastal observations are spatial evidence indicators and
should not be interpreted as verified property-risk assessments.
